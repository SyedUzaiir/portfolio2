# Portfolio Painting

An interactive, animated personal portfolio website that feels like a living watercolor painting. 

## Features
- **Watercolor Visual System**: Soft gradients and natural tones.
- **Day/Night Mode**: Smoothly transitioning animated sky, with moving sun, moon, and stars.
- **Interactive Cursor**: A watercolor bird follows your mouse with smooth easing.
- **Advanced Star System**: Floating, twinkling stars with parallax effects and shooting stars.
- **Modern UI**: Clean typography, glassmorphism, and responsive layout.

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Framer Motion
- TypeScript

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
